# Enterprise Hub

Enterprise Hub is a responsive business management dashboard built with Next.js.  
It includes independent modules for managing hardware store sales, basic grain sales, and property payment tracking.

## Live Demo

[View deployed app](https://manage-hub-gamma.vercel.app)

## Features

- Responsive dashboard layout
- Mobile sidebar and bottom navigation
- Hardware store sales module
- Basic grains inventory and sales module
- Property and land payment management module
- Sales history and payment tracking
- Inventory control with stock indicators
- Modern UI built with Material UI
- Deployed on Vercel

## Modules

### Dashboard

The main dashboard provides a general overview of the business, including sales, inventory status, pending payments, and activity summaries.

### Hardware Store

The hardware module allows users to:

- Manage products
- Control quantities and stock
- Register sales
- Calculate totals automatically
- Generate a sales history

### Basic Grains

The grains module works independently from the hardware module and allows users to:

- Manage grain inventory
- Register grain sales
- Control quantities and prices
- Track transaction history

### Real Estate / Properties

The property module allows users to:

- Register lands or properties
- Associate each property with a buyer
- Register partial payments
- Track payment dates
- View pending balances
- Monitor account status such as:
  - Up to date
  - Pending
  - Late
  - Fully paid
